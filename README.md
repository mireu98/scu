# GameHub - 게임 검색 설정

## 사용자의 목표
 - 사용자 : 원하는 조건의 게임을 빠르게 찾고 싶은 사람
 - 목표: 검색어(게임 이름)를 입력하거나 장르·플랫폼 등의 필터를 선택하여, 조건에 맞는 게임 목록을 확인하고 원하는 게임 정보를 조회한다.

## 사용자의 흐름
 1. 검색 페이지 접속: 메인 화면이나 상단 메뉴의 검색창/검색 버튼을 눌러 게임 검색 영역으로 이동한다.
 2. 검색어 입력 또는 필터 선택: 찾는 게임이 있다면 검색창에 게임 이름을 입력한다. 특정 종류의 게임을 원할 경우 장르(RPG, Action, FPS 등)나 플랫폼(PC, Mobile, Console) 태그를 선택한다.
 3. 검색 조건 적용: 검색 버튼을 누르거나 필터 옵션을 선택해 검색을 실행한다.
 4. 검색 결과 확인 및 정렬: 조건에 맞는 게임 목록을 확인한다. 필요 시 인기순, 최신순, 평점순 등으로 목록을 정렬한다.
 5. 게임 상세 정보 선택: 원하는 게임 카드를 클릭하여 해당 게임의 상세 페이지(소개, 탭 정보, 플레이 링크 등)로 이동한다.
 6. 검색 조건 재설정(필요 시): 원하는 결과가 나오지 않을 경우 '초기화' 버튼을 눌러 설정을 지우고 다시 검색한다.

 ## 인터렉션 시나리오
 1. 검색창을 클릭하거나 입력한다.
  - 검색창 테두리 색상이 활성화 된다.
  - 최근 검색어 및 추천 검색어 드롭다운 목록이 하단에 표시된다.
 2. 특정 장르 태그(예: RPG, Action) 버튼을 클릭한다.
  - 클릭한 태그 버튼의 스타일이 Active 상태(색상 변경 및 체크 아이콘 표시)로 전환된다.
  - 선택된 태그가 검색창 하단 '선택된 필터' 영역에 추가된다.
 3. 검색 실행 및 로딩
  - 검색창에 키워드 입력 후 Enter 키를 누르거나, 검색 버튼을 클릭한다.
  - 검색 버튼 내부에 스피너가 표시되며 목록 영역에 나타난다.
  - 검색 조건에 맞는 데이터를 불러온 후 목록이 서서히 나타난다.
 4. 검색 결과 및 카탈로그 인터랙션
  - 검색된 게임 카드 위에 마우스를 올린다.
  - 게임 카드가 살짝 위로 떠오르는 효과와 함께 게임의 짧은 대표 트레일러/GIF 또는 대표 태그가 미리보기로 출력된다.
  - 정렬 드롭다운을 클릭하여 옵션을 변경한다.
  - 별도의 페이지 뒤로가기 없이 목록이 해당 정렬 기준에 맞춰 실시간으로 다시 정렬되어 표시된다.
 5. 예외 처리 (검색 결과 없음)
  - 등록되지 않은 검색어를 입력하거나 일치하는 게임이 없는 필터를 선택한다.
  - "검색 결과가 없습니다" 안내 일러스트와 문구가 표시된다.
