# GameHub - 게임 검색 및 위시리스트 설정 서비스

GameHub는 신작 게임과 출시 예정 게임을 한눈에 확인하고, 사용자가 원하는 조건으로 게임을 검색한 뒤 위시리스트에 저장할 수 있는 게임 정보 웹 플랫폼의 중간 프로토타입입니다.

## 1. 서비스 및 사용자 경험 정의

- 주요 사용자: 신작 및 출시 예정 게임 정보를 찾고자 하는 게이머 및 게임 관심 이용자
- 서비스 목적: 다양한 게임 정보를 분류해 제공하고, 사용자가 입력한 조건에 따라 맞춤형 추천 게임을 매칭하여 전달
- 핵심 행동: 신작 게임 탭을 통한 정보 확인, 게임 검색 흐름 진행, 맞춤 검색 결과 확인 및 위시리스트 찜하기 액션


## 2. 새로 추가한 기능

7주차 기본 흐름(검색 정보 입력 > 장르 선택 > 요약 확인)에 이어지는 4단계 가상 검색 결과 생성 및 실시간 위시리스트(찜하기) 상태 토글 기능을 추가했습니다.

- 작동 원리: 3단계에서 '검색 실행'을 누르면 사용자가 입력한 제목과 선택한 장르formData 를 바탕으로 mockGameData와 연동되어 결과 카드가 동적으로 렌더링됩니다.
- 상태 변화: 4단계 결과 화면에서 '위시리스트' 찜하기 버튼을 클릭하면 실시간으로 버튼의 색상과 문구가 찜 완료 상태로 변경되어 피드백을 전달합니다.

## 3. 사용자 행동 및 상태별 반응 시나리오 & 테스트

| 구분 | 사용자 행동 | 조건 및 시스템 반응 | 다음 행동 안내 |
| 정상 경로 | 이름 입력 > 장르 선택 > 검색 실행 | 입력값 검증 통과 후 4단계로 이동, 입력 데이터 기반 결과 카드 출력 | 위시리스트 찜하기 클릭 또는 다시 검색 |
| 오류 분기 | 1단계에서 이름 없이 다음 클릭 | name-error 영역에 "게임 제목을 입력해주세요." 안내 문구 출력 및 테두리 강조 | 이름 재입력 후 다음 클릭 |
| 취소 분기 | 모달 창에서 취소 클릭 또는 ESC | 검색 플로우 전체 숨김 처리 hidden = true 및 동의 상태 해제 | 동의 체크박스 재선택 후 참여 |
| 상태 변화 | 4단계 결과에서 찜하기 클릭 | 버튼 텍스트가 위시리스트 찜 완료!로 바뀌고 색상 녹색 전환 | 클릭하여 찜 해제 가능 |
| 초기화 | 4단계에서 다시 검색 클릭 | 입력 폼 및 선택 상태, 결과 데이터 전체 초기화 후 플로우 닫기 | 메인 화면으로 복귀 |

## 4. 테스트 수행 결과

1. 정상 경로 테스트: 게임 이름 입력 후 RPG 장르 선택 > 4단계에서 추천 결과 카드 출력 및 찜하기 토글 작동 확인
2. 오류 처리 테스트: 공백 입력 후 다음 버튼 클릭 시 빨간 테두리와 안내 메시지가 뜨며 단계 이동이 차단됨을 확인 
3. 반응형 화면 테스트: 데스크톱 화면 및 모바일 화면에서 버튼과 레이아웃이 밀리지 않고 정상 작동함을 확인
