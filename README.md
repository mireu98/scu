## 이번 주 추가·수정한 기능 (신작 게임 입점 신청 폼)
- **추가된 기능**: 개발자 및 퍼블리셔 사용자가 직접 신작 게임의 입점(등록)을 신청할 수 있는 폼 인터랙션을 구현했습니다.
- **주요 구현 내용**:
  1. **조건부 입력 (`disabled` 제어)**: '유료 게임' 체크박스를 선택할 경우에만 희망 판매 가격 입력창이 나타나며 활성화(`disabled = false`)되고, 해제 시 숨겨지고 비활성화(`disabled = true`)됩니다.
  2. **입력 검증 및 피드백**: 게임 이름 입력 시 최소 2글자 미만일 경우 실시간으로 오류 문구와 빨간 테두리(`has-error`)가 표시되며, 올바르게 수정하면 즉시 해제됩니다.
  3. **제출 상태 처리 (`submit`)**: 폼 제출 시 버튼이 비활성화되고 "등록 심사 중..." 문구가 노출되어 중복 제출을 방지합니다. 1.5초 후 성공 메시지가 출력되며, 특정 단어("금지") 입력 시 실패 안내를 통해 기존 입력값이 유지된 채 재시도가 가능합니다.
  4. **초기화 기능**: '작성 초기화' 버튼을 통해 입력된 값, 에러 메시지, 조건부 입력 상태가 모두 초기 상태로 돌아갑니다.

## 확인 순서 (테스트 방법)
1. **조건부 입력 확인**: '유료 게임' 체크박스를 클릭하여 가격 입력창이 나타나는지, 체크 해제 시 사라지고 비활성화되는지 확인합니다.
2. **입력 검증 확인**: 게임 이름란에 한 글자만 입력하거나 빈 상태로 제출 시도하여 오류 문구와 테두리 변화를 확인합니다.
3. **정상 제출 및 중복 방지 확인**: 올바른 게임 이름을 입력하고 제출 버튼을 눌러 "등록 심사 중..." 상태로 버튼이 비활성화되는지, 잠시 뒤 성공 안내가 뜨는지 확인합니다.
4. **초기화 확인**: '작성 초기화' 버튼을 눌러 폼 전체가 깨끗하게 비워지는지 확인합니다.
